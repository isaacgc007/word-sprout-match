# Word Sprout Match

A touch-friendly English word and picture memory game for K3, P1 and P2 learners.

## Game rules

- Every game randomly chooses 8 words and makes 16 cards: 8 word cards and 8 picture cards.
- Very Easy shows all 16 cards from the start and ends after 3 wrong pairs.
- Easy games allow 15 wrong pairs; Hard games allow 10.
- Each match earns 100 points. Consecutive matches add a 25, 50, or 75 point streak bonus.
- A completed game adds 100 points on very easy, 200 on easy, or 300 on hard, plus 20 points for every raindrop left.
- Each matched pair earns one persistent star. Finishing adds 2 stars on very easy, 3 on easy, or 4 on hard, and a perfect game adds 2 more.
- Stars unlock 12 stickers in the saved sticker garden.

The library contains exactly 900 different entries: 300 K3 words, 300 P1 words, and 300 P2 words. Pictures use the device's emoji artwork so the site stays small and works offline.

## Play locally

Open `index.html`, or serve this folder with any static web server. A web server is recommended so offline caching can be tested.

## Publish free with GitHub Pages

The game is a static site and can be published directly from the repository's `main` branch. No server, database, API key, or paid service is needed.
